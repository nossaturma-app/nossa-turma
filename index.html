Horários das aulas

Toque num horário para tirar. Para incluir um novo (ex.: 11:00), use o campo abaixo.

Planos

Valores da tabela atual, usados para alunos novos. Quem já é aluno continua pagando o valor dele, que fica no cadastro de cada um.

Primeira mensalidade

Quando o aluno começa num dia diferente do vencimento. Vale para alunos novos (dá para trocar no cadastro de cada um).

Regras de reposição

Aviso fora do horário administrativo (madrugada, fim de semana) conta a partir da abertura seguinte. Aula que já é reposição não gera nova reposição. A reposição vale só dentro do mês da falta: no mês seguinte, zera.
